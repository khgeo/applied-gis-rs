# មេរៀនទី១៥៖ គម្រោងអនុវត្តបញ្ចប់វគ្គ និងក្រមសីលធម៌ទិន្នន័យ

!!! info "ព័ត៌មានមេរៀន"
    **រយៈពេលបង្រៀនដែលស្នើ៖ ៣ ម៉ោង** · មេរៀនទី ១៥ ក្នុងចំណោម ១៥

ក្នុងរយៈពេល ១៤ មេរៀន អ្នកបានរៀនការគណនាលើពពក ការត្រង និង composite ស្ថិតិតាមតំបន់ ស៊េរីពេលវេលា ការចាត់ថ្នាក់ ទឹកជំនន់ គ្រោះរាំងស្ងួត ទីសណ្ឋាន ព្រៃឈើ ស្រែ ទីក្រុង កំដៅ ការវិភាគពហុលក្ខខណ្ឌ និងកម្មវិធីវេប។ មេរៀនចុងក្រោយនេះមិនបង្រៀនបច្ចេកទេសថ្មីទេ។ វាបង្រៀនរបៀប **ប្រើបច្ចេកទេសទាំងនោះរួមគ្នា** លើបញ្ហាពិតមួយ ពីសំណួររហូតដល់លទ្ធផល ហើយរបៀបធ្វើវា **ដោយការទទួលខុសត្រូវ**។

ផែនទីមានអំណាច៖ វាអាចជួយបែងចែកជំនួយ ការពារព្រៃ ឬរៀបចំទីក្រុង ប៉ុន្តែវាក៏អាចបង្ហាញទីតាំងរសើប បំភាន់អ្នកសម្រេចចិត្តដោយភាពប្រាកដក្លែងក្លាយ ឬខកសហគមន៍ដែលមិនមាននៅក្នុងទិន្នន័យ។ មេរៀននេះរៀបចំអ្នកសម្រាប់គម្រោងបញ្ចប់វគ្គ និងការងារវិជ្ជាជីវៈក្រោយការសិក្សា។

## ១៥.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. សរសេរសំណួរស្រាវជ្រាវអនុវត្តដែលច្បាស់ មានអ្នកប្រើ និងអាចឆ្លើយបានក្នុងរយៈពេលគម្រោង។
2. រៀបចំសំណើគម្រោងមួយទំព័រ ដែលមានទិន្នន័យ វិធីសាស្ត្រ ការផ្ទៀងផ្ទាត់ និងកាលវិភាគ។
3. អនុវត្តបញ្ជីពិនិត្យភាពអាចធ្វើឡើងវិញ លើស្គ្រីប Earth Engine របស់ខ្លួន។
4. ទំនាក់ទំនងភាពមិនប្រាកដ និងដែនកំណត់ ក្នុងផែនទី តារាង និងអត្ថបទ។
5. វាយតម្លៃហានិភ័យក្រមសីលធម៌នៃគម្រោងមួយ (ឯកជនភាព គ្រោះថ្នាក់ យុត្តិធម៌ អាជ្ញាបណ្ណ) ហើយស្នើវិធានការកាត់បន្ថយ។

### ចំណេះដឹងមុនត្រូវមាន

- មេរៀនទី១–១៤។ ជាពិសេសផ្នែក «អ្វីដែលយើងមិនអាចសន្និដ្ឋាន» នៃមេរៀននីមួយៗ។

## ១៥.២. ស្ថានភាពបើកមេរៀន៖ ផែនទីដែលល្អពេក

ក្រុមនិស្សិតមួយធ្វើផែនទីការបាត់បង់ព្រៃលម្អិត នៅជុំវិញភូមិមួយក្បែរតំបន់ការពារ ហើយបង្ហោះលើបណ្ដាញសង្គម ដោយដាក់ចំណងជើង «ការកាប់ព្រៃខុសច្បាប់»។ ផែនទីនោះមានភាពស្រស់ស្អាត ប៉ុន្តែ៖ ក្រឡាបាត់បង់មួយភាគធំជាចម្ការកៅស៊ូដែលត្រូវបានច្រូតស្របច្បាប់ ផែនទីបង្ហាញផ្ទះគ្រួសារមួយចំនួន ហើយគ្មានការពិភាក្សាជាមួយសហគមន៍ទេ។ គ្រួសារខ្លះត្រូវបានគេចោទប្រកាន់ដោយមិនពិត។

សំណួរដែលមេរៀននេះឆ្លើយ៖

- តើគម្រោងអនុវត្តល្អ ចាប់ផ្ដើមយ៉ាងដូចម្ដេច?
- តើត្រូវធ្វើឲ្យអ្នកដទៃអាចត្រួតពិនិត្យ និងធ្វើតាមការងាររបស់យើងបានដោយរបៀបណា?
- តើត្រូវនិយាយពីអ្វីដែលយើងមិនដឹង ដោយស្មោះត្រង់យ៉ាងណា?
- តើត្រូវសួរសំណួរក្រមសីលធម៌អ្វីខ្លះ មុនចែករំលែកផែនទី?

## ១៥.៣. ទ្រឹស្ដីស្នូល

### ១៥.៣.១. វដ្ដគម្រោង

{{FIG:a15-cycle}}

គម្រោងអនុវត្តល្អ **ចាប់ផ្ដើមពីសំណួរ មិនមែនពីទិន្នន័យ**។ «ខ្ញុំចង់ប្រើ Sentinel-1» មិនមែនជាសំណួរទេ។ «តើស្រែប៉ុន្មានហិកតានៅស្រុក X លិចទឹកក្នុងខែតុលា ២០២៤ ហើយភូមិណាខ្លះរងផលប៉ះពាល់ច្រើនបំផុត?» ជាសំណួរដែលអាចឆ្លើយបាន។ លក្ខណៈនៃសំណួរល្អ៖

- **ច្បាស់**៖ អ្វី នៅទីណា ពេលណា។
- **មានអ្នកប្រើ**៖ អ្នកណានឹងប្រើចម្លើយ ហើយសម្រាប់ការសម្រេចចិត្តអ្វី។
- **អាចឆ្លើយបាន**៖ មានទិន្នន័យ ក្រឡាសមស្រប និងវិធីផ្ទៀងផ្ទាត់។
- **តូចល្មម**៖ អាចបញ្ចប់ក្នុង ៤–៦ សប្ដាហ៍។

សំណើមួយទំព័រ បង្ខំឲ្យអ្នកគិតតាមជំហាននីមួយៗ មុនសរសេរកូដ៖ ចំណងជើង បញ្ហា និងអ្នកប្រើ សំណួរ តំបន់ និងរយៈពេល ទិន្នន័យ (ID Earth Engine ក្រឡា អាជ្ញាបណ្ណ) វិធីសាស្ត្រ (ជំហាន និងមេរៀនពាក់ព័ន្ធ) ការផ្ទៀងផ្ទាត់ និងលទ្ធផល និងកាលវិភាគ។ ពុម្ពពេញលេញមានក្នុង [លំហាត់ទី១៥](../workbook/lab-15.md)។

### ១៥.៣.៣. ភាពអាចធ្វើឡើងវិញ

{{FIG:a15-reproducible}}

**ភាពអាចធ្វើឡើងវិញ (reproducibility)** មានន័យថា អ្នកផ្សេងអាចរត់ការងាររបស់អ្នក ហើយបានលទ្ធផលដូចគ្នា។ ក្នុង Earth Engine នេះងាយជាងកម្មវិធីលើកុំព្យូទ័រ ព្រោះទិន្នន័យ និងការគណនាស្ថិតនៅលើពពក ប៉ុន្តែត្រូវការវិន័យ៖

```javascript
// ===== ការកំណត់ (កែតែផ្នែកនេះ) =====
var CONFIG = {
  province: 'Takeo',
  year: 2024,
  hansen: 'UMD/hansen/global_forest_change_2023_v1_11',
  threshold: 30,          // % គម្របដើមឈើ
  seed: 42,               // randomColumn និង classifier
  scale: 10
};
// ===== កូដខាងក្រោមប្រើតែ CONFIG =====
```

ចំណុចសំខាន់៖ ស្គ្រីបរត់ពីដើមដល់ចប់ ដោយគ្មានការកែដោយដៃ · ID និងកំណែទិន្នន័យ · seed · Asset ដែលចែករំលែក · README ដែលពន្យល់របៀបរត់ និងលទ្ធផល · រក្សាទុកក្នុង Git។ Earth Engine ធ្វើបច្ចុប្បន្នភាព collection ជាប្រចាំ (រូបភាពថ្មី ការកែតម្រូវ) ដូច្នេះកាលបរិច្ចេទដែលអ្នករត់ ក៏ជាផ្នែកនៃលទ្ធផលដែរ។

### ១៥.៣.៤. ការទំនាក់ទំនងភាពមិនប្រាកដ

{{FIG:a15-uncertainty}}

ផែនទីដែលមើលទៅប្រាកដពេក អាចនាំឲ្យសម្រេចចិត្តខុស។ វិធីទំនាក់ទំនងភាពមិនប្រាកដ៖

- **លេខជាមួយចន្លោះ**៖ «៣២០ ± ៤០ គម²» ឬ «២៨០–៣៦០ គម² អាស្រ័យលើកម្រិត»។
- **ភាពត្រឹមត្រូវតាមថ្នាក់**៖ OA PA និង UA (មេរៀនទី៦)។
- **សេណារីយ៉ូ**៖ លទ្ធផលពីកម្រិត ឬទម្ងន់ខុសគ្នា (មេរៀនទី១០ ១៣)។
- **ផែនទីទំនុកចិត្ត**៖ ចំនួនការសង្កេតស្អាត (មេរៀនទី៣) ឬភាពយល់ស្របរវាងវិធីពីរ។
- **ពាក្យ**៖ «ទំនង» «សញ្ញា» «ប៉ាន់ស្មាន» ជំនួស «បញ្ជាក់» នៅពេលទិន្នន័យមិនអាចបញ្ជាក់។
- **ផ្នែកដែនកំណត់**៖ ដូច «អ្វីដែលយើងមិនអាចសន្និដ្ឋាន» ក្នុងគ្រប់មេរៀន។

**១. ឯកជនភាព**៖ រូបភាពគុណភាពខ្ពស់ (Google Earth ដ្រូន) បង្ហាញផ្ទះ យានយន្ត និងមនុស្ស។ ផែនទីដែលភ្ជាប់ទីតាំងផ្ទះជាមួយព័ត៌មានផ្ទាល់ខ្លួន (ឈ្មោះ ចំណូល ជំងឺ) ត្រូវការការយល់ព្រម និងការការពារ។ បង្ហាញលទ្ធផលជាតំបន់ (ភូមិ ឃុំ) ជំនួសឲ្យផ្ទះនីមួយៗ នៅពេលអាច។

**២. គ្មានគ្រោះថ្នាក់**៖ ទីតាំងសត្វព្រៃកម្រ ធនធានដែលងាយរងការលួច ឬសហគមន៍ងាយរងគ្រោះ អាចត្រូវបានប្រើខុសគោលបំណង។ សួរ៖ «ប្រសិនបើផែនទីនេះធ្លាក់ក្នុងដៃខុស តើអាចមានគ្រោះថ្នាក់អ្វី?»

**៣. យុត្តិធម៌**៖ ទិន្នន័យសកល (WorldPop Open Buildings WorldCover) អាចខកសហគមន៍ជនបទ ជនជាតិដើមភាគតិច ឬការតាំងលំនៅក្រៅផ្លូវការ។ ការសម្រេចដែលផ្អែកតែលើទិន្នន័យទាំងនេះ អាចធ្វើឲ្យពួកគេត្រូវបានមើលរំលង។

**៤. តម្លាភាព**៖ រាយការណ៍វិធីសាស្ត្រ ដែនកំណត់ និងអ្នកផ្ដល់មូលនិធិ។ កុំលាក់លទ្ធផលដែលមិនស្របនឹងការរំពឹងទុក។

**៥. ការគោរព**៖ គោរពអាជ្ញាបណ្ណ ដកស្រង់ប្រភព ហើយពិភាក្សាលទ្ធផលជាមួយអ្នកដែលរងផលប៉ះពាល់ មុនបោះពុម្ពផ្សាយ ជាពិសេសនៅពេលលទ្ធផលអាចនាំទៅការចោទប្រកាន់ ឬការប្ដូរគោលនយោបាយ។

## ១៥.៤. ឧទាហរណ៍ដែលបានដោះស្រាយ៖ ពីគំនិតទៅសំណើ

### ជំហានទី១៖ ពីប្រធានបទ ទៅសំណួរ

ប្រធានបទ៖ «គ្រោះរាំងស្ងួតនៅខេត្តកំពង់ស្ពឺ»។ ធំពេក។ ធ្វើឲ្យតូចល្មម៖ «តើស្រុកណាខ្លះនៃខេត្តកំពង់ស្ពឺ មានសញ្ញាគ្រោះរាំងស្ងួតកសិកម្ម (SPI-៣ < −១ និង VHI < ៤០ លើដីដំណាំ) ក្នុងរដូវវស្សាឆ្នាំ ២០១៩ និង ២០២៣ ហើយតើលំនាំទាំងពីរឆ្នាំស្រដៀងគ្នាឬទេ?» អ្នកប្រើ៖ មន្ទីរកសិកម្មខេត្ត ដែលរៀបចំផែនការស្រះសហគមន៍ (មេរៀនទី១៣)។

### ជំហានទី២៖ ទិន្នន័យ និងវិធីសាស្ត្រ

CHIRPS (SPI-៣ សាមញ្ញ ធៀបនឹង ១៩៩១–២០២០) · MODIS MOD13Q1 និង MOD11A2 (VHI) · WorldCover (mask ដំណាំ) · GAUL level 2 (ស្រុក)។ វិធីសាស្ត្រតាមមេរៀនទី៨ ជាមួយតារាងស្រុក (មេរៀនទី៤)។

### ជំហានទី៣៖ ការផ្ទៀងផ្ទាត់

ប្រៀបធៀបជាមួយរបាយការណ៍ខូចខាតដំណាំរបស់មន្ទីរ (ប្រសិនបើអាចរក) ព័ត៌មានសារព័ត៌មាន និងការសម្ភាសន៍កសិករ ២–៣ នាក់ក្នុងស្រុកដែលមានសញ្ញាខ្លាំង និងស្រុកដែលមិនមាន។

### ជំហានទី៤៖ ក្រមសីលធម៌

លទ្ធផលជាស្ថិតិតាមស្រុក (គ្មានព័ត៌មានផ្ទាល់ខ្លួន)។ ការសម្ភាសន៍ត្រូវការការយល់ព្រម និងមិនបង្ហាញឈ្មោះ។ លទ្ធផលត្រូវចែករំលែកជាមួយមន្ទីរមុនបោះពុម្ពផ្សាយ។

### ជំហានទី៥៖ កាលវិភាគ

សប្ដាហ៍ទី១ សំណើ · សប្ដាហ៍ទី២–៣ ស្គ្រីប និងលទ្ធផលដំបូង · សប្ដាហ៍ទី៤ ផ្ទៀងផ្ទាត់ និងភាពរសើប · សប្ដាហ៍ទី៥ ផែនទី និងកម្មវិធី · សប្ដាហ៍ទី៦ របាយការណ៍ និងបទបង្ហាញ។

> «គម្រោងនេះនឹងប្រើ CHIRPS និង MODIS ដើម្បីកំណត់ស្រុកដែលមានសញ្ញាគ្រោះរាំងស្ងួតកសិកម្ម ក្នុងរដូវវស្សាពីរឆ្នាំ El Niño ហើយផ្ដល់តារាង ផែនទី និងកម្មវិធីវេបសាមញ្ញ ដល់មន្ទីរកសិកម្មខេត្តកំពង់ស្ពឺ ដោយរាយការណ៍ដែនកំណត់នៃទិន្នន័យពេញលេញ។»

## ១៥.៦. ការយល់ច្រឡំដែលត្រូវប្រុងប្រយ័ត្ន

**១. «គម្រោងល្អចាប់ផ្ដើមពីទិន្នន័យថ្មីៗ»**
គម្រោងល្អចាប់ផ្ដើមពីសំណួរ និងអ្នកប្រើ។ ទិន្នន័យត្រូវបានជ្រើសតាមសំណួរ។

**២. «ផែនទីស្អាត = គម្រោងល្អ»**
ពិន្ទុភាគច្រើនមកពីវិធីសាស្ត្រ និងការផ្ទៀងផ្ទាត់។ ផែនទីស្អាតដែលគ្មានការផ្ទៀងផ្ទាត់ អាចបំភាន់។

**៣. «ការនិយាយពីដែនកំណត់ ធ្វើឲ្យការងារមើលទៅខ្សោយ»**
វាធ្វើឲ្យការងារគួរឲ្យទុកចិត្ត។ អ្នកសម្រេចចិត្តត្រូវដឹងថាពួកគេអាចពឹងលើលទ្ធផលប៉ុណ្ណា។

**៤. «ទិន្នន័យសាធារណៈ គ្មានបញ្ហាក្រមសីលធម៌»**
ការរួមបញ្ចូលទិន្នន័យសាធារណៈ អាចបង្កើតព័ត៌មានរសើប (ឧ. ទីតាំងផ្ទះ + ព័ត៌មានស្ទង់មតិ)។

**៥. «ឥតគិតថ្លៃ = ប្រើបានតាមចិត្ត»**
ទិន្នន័យ និង Earth Engine មានលក្ខខណ្ឌប្រើប្រាស់ និងការដកស្រង់។

## ១៥.៧. សេចក្ដីសង្ខេបមេរៀន

គម្រោងអនុវត្តល្អ ធ្វើតាមវដ្ដ៖ សំណួរ ទិន្នន័យ វិធីសាស្ត្រ ការផ្ទៀងផ្ទាត់ និងទំនាក់ទំនង ដោយចាប់ផ្ដើមពីសំណួរដែលច្បាស់ មានអ្នកប្រើ និងតូចល្មម។ សំណើមួយទំព័រ ភាពអាចធ្វើឡើងវិញ (CONFIG seed កំណែ README Git) និងការទំនាក់ទំនងភាពមិនប្រាកដដោយស្មោះត្រង់ ធ្វើឲ្យការងារអាចទុកចិត្តបាន។

ក្រមសីលធម៌ទិន្នន័យភូមិសាស្ត្រមានប្រាំគោលការណ៍៖ ឯកជនភាព គ្មានគ្រោះថ្នាក់ យុត្តិធម៌ តម្លាភាព និងការគោរព។ ទិន្នន័យឥតគិតថ្លៃនៅតែមានលក្ខខណ្ឌអាជ្ញាបណ្ណ និងការដកស្រង់។

!!! abstract "គំនិតស្នូលនៃមេរៀន និងនៃសៀវភៅ"
    ការយកព័ត៌មានពីចម្ងាយ និង GIS ផ្ដល់សមត្ថភាពមើលប្រទេសទាំងមូល តាមពេលវេលា។ តម្លៃរបស់សមត្ថភាពនោះ អាស្រ័យលើសំណួរដែលយើងសួរ ភាពស្មោះត្រង់ដែលយើងរាយការណ៍ចម្លើយ និងការយកចិត្តទុកដាក់ចំពោះមនុស្សដែលរស់នៅក្នុងផែនទីរបស់យើង។

## ១៥.៩. សំណួររំលឹក និងវាយតម្លៃ

### ក. សំណួរយល់ដឹង

1. រាយលក្ខណៈបួននៃសំណួរស្រាវជ្រាវអនុវត្តល្អ។
2. ពន្យល់ភាពអាចធ្វើឡើងវិញ ហើយរាយការអនុវត្តប្រាំ ក្នុង Earth Engine។
3. រាយវិធីបួនដើម្បីទំនាក់ទំនងភាពមិនប្រាកដ។
4. ពន្យល់គោលការណ៍ក្រមសីលធម៌ទាំងប្រាំ ជាមួយឧទាហរណ៍មួយនីមួយៗ។
5. ហេតុអ្វីទិន្នន័យឥតគិតថ្លៃ នៅតែត្រូវដកស្រង់?

### ខ. សំណួរអនុវត្តគោលគំនិត

6. កែប្រធានបទ «ទីក្រុងភ្នំពេញ» ទៅជាសំណួរស្រាវជ្រាវដែលអាចឆ្លើយបាន។
7. សរសេរ CONFIG សម្រាប់គម្រោងផែនទីស្រែ (មេរៀនទី១១)។
8. ស្ថានភាព៖ ផែនទីរបស់អ្នកបង្ហាញសំណង់ក្រៅផ្លូវការ ដែលអាចត្រូវបណ្ដេញចេញ។ តើអ្នកនឹងចែករំលែកវាដោយរបៀបណា ឬមិនចែករំលែក?
9. សរសេរបន្ទាត់ដកស្រង់ទិន្នន័យ សម្រាប់ផែនទីទឹកជំនន់ពីមេរៀនទី៧។
10. ជ្រើសលំហាត់មួយដែលអ្នកបានធ្វើ ហើយសរសេរផ្នែក «អ្វីដែលយើងមិនអាចសន្និដ្ឋាន» ឡើងវិញ ឲ្យបានលម្អិតជាងមុន។

### គ. កិច្ចការខ្លី

សរសេរសំណើគម្រោងមួយទំព័រ តាមពុម្ពក្នុងរូប ១៥.២ សម្រាប់គម្រោងបញ្ចប់វគ្គរបស់អ្នក។

## កំណត់សម្គាល់សម្រាប់គ្រូបង្រៀន

### ក. ការបែងចែកពេលវេលា ១៨០ នាទី

| សកម្មភាព | ពេលវេលា |
|---|---:|
| ស្ថានភាពបើកមេរៀន៖ ផែនទីដែលល្អពេក | ១៥ នាទី |
| វដ្ដគម្រោង និងសំណួរល្អ | ២៥ នាទី |
| សំណើ · ភាពអាចធ្វើឡើងវិញ | ២៥ នាទី |
| ភាពមិនប្រាកដ | ២០ នាទី |
| ក្រមសីលធម៌ · ពិសោធន៍សេណារីយ៉ូ (ពិភាក្សាក្រុម) | ៤០ នាទី |
| អាជ្ញាបណ្ណ · លក្ខណៈវិនិច្ឆ័យ | ១៥ នាទី |
| បទបង្ហាញសំណើ ២ នាទី | ៤០ នាទី |
| **សរុប** | **១៨០ នាទី / ៣ ម៉ោង** |

### ខ. ការណែនាំគម្រោង

- អនុម័តសំណើនៅសប្ដាហ៍ទី១ មុននិស្សិតចាប់ផ្ដើមសរសេរកូដ។ ច្រានចោលសំណើដែលធំពេក ឬគ្មានការផ្ទៀងផ្ទាត់។
- គម្រោងអាចធ្វើជាក្រុម ២–៣ នាក់ ប៉ុន្តែម្នាក់ៗត្រូវពន្យល់ផ្នែករបស់ខ្លួនក្នុងបទបង្ហាញ។
- លើកទឹកចិត្តប្រធានបទដែលមានអ្នកប្រើពិត (មន្ទីរ អង្គការ សហគមន៍) និងដែលភ្ជាប់ទៅខេត្តកំណើតរបស់និស្សិត។

### គ. បញ្ចប់វគ្គ

វគ្គនេះបញ្ចប់ស៊េរីសៀវភៅទាំងបួន៖ ផែនទីវិទ្យា មូលដ្ឋានគ្រឹះ GIS មូលដ្ឋានគ្រឹះការយកព័ត៌មានពីចម្ងាយ និង GIS និងការយកព័ត៌មានពីចម្ងាយអនុវត្តន៍។ និស្សិតដែលចង់បន្ត អាចសិក្សាការរៀនម៉ាស៊ីន (deep learning) សម្រាប់រូបភាព Python និង geemap ឬកម្មវិធីដ្រូន និងគំរូបីវិមាត្រ។
