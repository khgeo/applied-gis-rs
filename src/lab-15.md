## ស្ថានភាព

អ្នកនឹងអនុវត្តគម្រោងអនុវត្តមួយ ពីសំណួររហូតដល់លទ្ធផល លើបញ្ហាពិតនៅកម្ពុជា ដោយប្រើវិធីសាស្ត្រពីមេរៀនយ៉ាងហោចណាស់ពីរ ជំពូកផ្សេងគ្នា។ លំហាត់នេះផ្ដល់ពុម្ព កាលវិភាគ និងលក្ខណៈវិនិច្ឆ័យ។

## គោលបំណង

- សរសេរសំណើមួយទំព័រ ដែលត្រូវបានអនុម័តដោយគ្រូ។
- អនុវត្តការវិភាគដែលអាចធ្វើឡើងវិញ ក្នុង Earth Engine។
- ផ្ទៀងផ្ទាត់លទ្ធផល និងរាយការណ៍ភាពមិនប្រាកដ។
- ប្រគល់របាយការណ៍ ផែនទី ស្គ្រីប (និងកម្មវិធីជាជម្រើស) និងបទបង្ហាញ ១០ នាទី។

## ពិសោធន៍មុនចាប់ផ្ដើម · ១០ នាទី

ឆ្លើយសេណារីយ៉ូទាំងអស់ ហើយកត់ត្រាសេណារីយ៉ូមួយដែលពាក់ព័ន្ធនឹងគម្រោងរបស់អ្នកបំផុត។

## សកម្មភាពទី១៖ សំណើ · សប្ដាហ៍ទី១

សរសេរសំណើមួយទំព័រ តាមពុម្ព៖

| ផ្នែក | មាតិកា |
|---|---|
| ១. ចំណងជើង | ខ្លី ច្បាស់ មានទីកន្លែង និងពេលវេលា |
| ២. បញ្ហា និងអ្នកប្រើ | ហេតុអ្វីសំខាន់ · អ្នកណានឹងប្រើ · សម្រាប់ការសម្រេចចិត្តអ្វី |
| ៣. សំណួរស្រាវជ្រាវ | ១–២ សំណួរ ដែលអាចឆ្លើយបាន |
| ៤. តំបន់ និងរយៈពេល | AOI · ឆ្នាំ · រដូវ · ផែនទីទីតាំងតូចមួយ |
| ៥. ទិន្នន័យ | ID Earth Engine · ក្រឡា · រយៈពេល · អាជ្ញាបណ្ណ |
| ៦. វិធីសាស្ត្រ | ជំហាន ៥–៨ · មេរៀនពាក់ព័ន្ធ (យ៉ាងហោចណាស់ពីរជំពូក) |
| ៧. ការផ្ទៀងផ្ទាត់ | ចំណុច · ស្ថិតិ · ការពិនិត្យដោយភ្នែក · ភាពរសើប |
| ៨. ក្រមសីលធម៌ | ហានិភ័យ និងវិធានការ (ឯកជនភាព គ្រោះថ្នាក់ យុត្តិធម៌) |
| ៩. លទ្ធផល និងកាលវិភាគ | ផែនទី តារាង កម្មវិធី · ផែនការប្រចាំសប្ដាហ៍ |

គ្រូអនុម័ត ឬស្នើកែ មុនអ្នកចាប់ផ្ដើមសរសេរកូដ។

## សកម្មភាពទី២៖ ស្គ្រីប · សប្ដាហ៍ទី២–៣

រៀបចំស្គ្រីបតាមរចនាសម្ព័ន្ធនេះ៖

```javascript
// ===== គម្រោង៖ [ចំណងជើង] · អ្នកនិពន្ធ៖ [ឈ្មោះ] · កាលបរិច្ឆេទរត់៖ [YYYY-MM-DD] =====
// ===== ១. CONFIG (កែតែផ្នែកនេះ) =====
var CONFIG = {aoiName: 'Takeo', year: 2024, seed: 42, scale: 10};
// ===== ២. តំបន់ និងទិន្នន័យ =====
// ===== ៣. ការវិភាគ =====
// ===== ៤. ការផ្ទៀងផ្ទាត់ =====
// ===== ៥. លទ្ធផល (Map · print · Export) =====
```

ចែករំលែក Asset ទាំងអស់ «Anyone can read» ហើយរក្សាស្គ្រីប និង README ក្នុង GitHub (ជាជម្រើស តែណែនាំ)។

## សកម្មភាពទី៣៖ ផ្ទៀងផ្ទាត់ · សប្ដាហ៍ទី៤

អនុវត្តយ៉ាងហោចណាស់ពីរ៖ តារាងកំហុសពីចំណុចឯករាជ្យ · ការប្រៀបធៀបជាមួយស្ថិតិ ឬរបាយការណ៍ · ការវិភាគភាពរសើប (កម្រិត ឬទម្ងន់) · ការពិនិត្យគំរូដោយភ្នែក ២០ ចំណុច។ សរសេរផ្នែក «អ្វីដែលយើងមិនអាចសន្និដ្ឋាន» ដូចក្នុងមេរៀន។

## សកម្មភាពទី៤៖ ផែនទី និងកម្មវិធី · សប្ដាហ៍ទី៥

ផែនទីយ៉ាងហោចណាស់ពីរ (QGIS · តាមគោលការណ៍សៀវភៅទី១៖ ចំណងជើង legend មាត្រដ្ឋាន ទិសខាងជើង ប្រភព ការដកស្រង់)។ ជាជម្រើស៖ កម្មវិធី Earth Engine (លំហាត់ទី១៤) ដែលបង្ហាញលទ្ធផលសំខាន់។

## សកម្មភាពទី៥៖ របាយការណ៍ និងបទបង្ហាញ · សប្ដាហ៍ទី៦

**របាយការណ៍** ៨–១២ ទំព័រ៖ សេចក្ដីសង្ខេប (១៥០ ពាក្យ) · សេចក្ដីផ្ដើម · តំបន់ និងទិន្នន័យ · វិធីសាស្ត្រ · លទ្ធផល · ការផ្ទៀងផ្ទាត់ និងភាពមិនប្រាកដ · ការពិភាក្សា និងដែនកំណត់ · ក្រមសីលធម៌ · សេចក្ដីសន្និដ្ឋាន · ឯកសារយោង · ឧបសម្ព័ន្ធ (តំណស្គ្រីប)។

**បទបង្ហាញ** ១០ នាទី + សំណួរ ៥ នាទី៖ សំណួរ · វិធីសាស្ត្រ (រូបមួយ) · លទ្ធផលសំខាន់ ២–៣ · ដែនកំណត់ · អ្វីដែលអ្នកប្រើគួរធ្វើ។
