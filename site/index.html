    សៀវភៅទី៤៖ អនុវត្តន៍ GIS និងការយកព័ត៌មានពីចម្ងាយ¶

    សម្រាប់វគ្គសិក្សា ១ ឆមាស · ៤៥ ម៉ោង · ១៥ មេរៀន · ១៥ លំហាត់ Earth Engine · ជាភាសាខ្មែរ¶

    សៀវភៅនេះជាឯកសារបង្រៀនសម្រាប់មុខវិជ្ជា អនុវត្តន៍ GIS និងការយកព័ត៌មានពីចម្ងាយ (Applied GIS and Remote Sensing) កម្រិតបរិញ្ញាបត្រ ឆ្នាំទី៣ ឆមាសទី២ ដេប៉ាតឺម៉ង់ភូមិវិទ្យា និងរៀបចំដែនដី។ វាមាន ១៥ មេរៀនទ្រឹស្ដី និងអនុវត្ត (៣ ម៉ោងក្នុងមួយមេរៀន) និង សៀវភៅអនុវត្ត ១៥ លំហាត់ ដែលប្រើ Google Earth Engine ដើម្បីវិភាគរូបភាពផ្កាយរណបរាប់ពាន់ផ្ទាំងលើកម្ពុជា ដោយមិនចាំបាច់ទាញយកទិន្នន័យ។

    សៀវភៅទី២ និងទី៣ បង្រៀន «ហេតុអ្វី» និង «យ៉ាងដូចម្ដេច» លើរូបភាព ឬស្រទាប់មួយៗក្នុង QGIS។ សៀវភៅនេះបង្រៀនរបៀបធ្វើការងារដដែលនោះ លើប្រទេសទាំងមូល និងលើរយៈពេលរាប់ឆ្នាំ ហើយអនុវត្តវាលើបញ្ហាពិតរបស់កម្ពុជា៖ ទឹកជំនន់ គ្រោះរាំងស្ងួត ការបាត់បង់ព្រៃ ស្រែ និងការពង្រីកទីក្រុង។

    ស្លាយបង្រៀន បើក Earth Engine Code Editor កំណែ offline (ZIP)

    ស៊េរីសៀវភៅទាំង ៤¶

    សៀវភៅនេះជាផ្នែកមួយនៃស៊េរីសម្រាប់ឆ្នាំទី២ និងទី៣។ មើលស៊េរីទាំងមូលនៅ khgeo.github.io។

    សៀវភៅ ចំណងជើង ឆ្នាំ/ឆមាស
    ទី១ ផែនទីវិទ្យា ឆ្នាំទី២ ឆមាសទី១
    ទី២ មូលដ្ឋានគ្រឹះនៃ GIS ឆ្នាំទី២ ឆមាសទី២
    ទី៣ មូលដ្ឋានគ្រឹះនៃការយកព័ត៌មានពីចម្ងាយ ឆ្នាំទី៣ ឆមាសទី១
    ទី៤ អនុវត្តន៍ GIS និងការយកព័ត៌មានពីចម្ងាយ ← សៀវភៅនេះ ឆ្នាំទី៣ ឆមាសទី២

    អ្វីដែលសៀវភៅនេះបង្រៀន និងមិនបង្រៀន

    សៀវភៅនេះបង្រៀន ការគណនាលើពពក (Google Earth Engine) JavaScript សម្រាប់ការវិភាគលំហ ការត្រង និងការបង្កើត composite ស្ថិតិតាមតំបន់ ស៊េរីពេលវេលា ការចាត់ថ្នាក់ដោយ Random Forest និង ការអនុវត្ត លើទឹកជំនន់ គ្រោះរាំងស្ងួត ទីសណ្ឋាន ព្រៃឈើ កសិកម្ម ទីក្រុង និងការសម្រេចចិត្តពហុលក្ខខណ្ឌ ព្រមទាំងការចែករំលែកលទ្ធផលជាកម្មវិធីវេប។

    រូបវិទ្យានៃរលក សញ្ញាណស្ពិចត្រាល់ សន្ទស្សន៍ និងទ្រឹស្ដីការចាត់ថ្នាក់ ជាខ្លឹមសារសៀវភៅទី៣ ហើយ ស្រទាប់វ៉ិចទ័រ មូលទិន្នន័យ បាហ្វ័រ និងការត្រួតស្រទាប់ ជាខ្លឹមសារសៀវភៅទី២។ សៀវភៅនេះប្រើពួកវាជាឧបករណ៍ ដោយមិនបង្រៀនឡើងវិញ។

    អានដោយគ្មានអ៊ីនធឺណិត¶

    • ទូរសព្ទ ឬកុំព្យូទ័រផ្ទាល់ខ្លួន៖ ចុចប៊ូតុងខាងលើម្ដង ពេលមាន Wi-Fi។ ក្រោយមក បើកតំណ khgeo.github.io/applied-gis-rs ដដែល ទោះគ្មានអ៊ីនធឺណិតក៏បាន។ មេរៀន លំហាត់ ស្លាយបង្រៀន និងពិសោធន៍ ត្រូវបានរក្សាទុកទាំងអស់។ លើទូរសព្ទ ប្រើ «Add to Home screen» ដើម្បីបើកដូចកម្មវិធី។
    • កុំព្យូទ័របន្ទប់ពិសោធន៍ ឬគ្មានអ៊ីនធឺណិតសោះ៖ ទាញយក កំណែ offline (ZIP) ចម្លងតាម USB ពន្លា (Extract) ហើយបើក START_HERE.html ក្នុង Chrome, Edge ឬ Firefox។ មិនចាំបាច់ដំឡើងអ្វីទេ។
    • ស្លាយបើកជារបៀបបញ្ចាំង (slide show) ពេញអេក្រង់បានទាំងពីររបៀប។ ផែនទីផ្ទៃក្រោយ OpenStreetMap ក្នុងលំហាត់ តំណខាងក្រៅ និង Earth Engine នៅតែត្រូវការអ៊ីនធឺណិត។

    ចាប់ផ្ដើមពីណា?¶

    • សម្រាប់និស្សិត

      ចុះឈ្មោះ Earth Engine ដោយមើល ឧបសម្ព័ន្ធ ក រួចចាប់ផ្ដើមពី មេរៀនទី១។ ត្រូវការតែកម្មវិធីរុករក និងគណនី Google ប៉ុណ្ណោះ។

    • សម្រាប់គ្រូបង្រៀន

      មើល កម្មវិធីសិក្សា សម្រាប់ការបែងចែក ៤៥ ម៉ោង។ មេរៀននីមួយៗមានស្លាយ ៦០–៨០ ផ្ទាំង និងកំណត់សម្គាល់សម្រាប់គ្រូ។

    • កូដ Earth Engine

      គ្រប់ឧទាហរណ៍មានប៊ូតុងចម្លង។ បិទភ្ជាប់ក្នុង Code Editor ហើយចុច Run។ កូដសរសេរសម្រាប់ JavaScript API។

    • ទិន្នន័យកម្ពុជា

      ឧបសម្ព័ន្ធ ខ រាយទិន្នន័យ Earth Engine ដែលប្រើក្នុងវគ្គ៖ Sentinel-1/2 Landsat CHIRPS SRTM Hansen GFC និងព្រំរដ្ឋបាល។
