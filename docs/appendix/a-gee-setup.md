# ឧបសម្ព័ន្ធ ក៖ ចុះឈ្មោះ និងរៀបចំ Earth Engine

## ១. អ្វីដែលត្រូវការ

- គណនី Google (Gmail ឬគណនីសាកលវិទ្យាល័យ)។
- កម្មវិធីរុករក Chrome ឬ Firefox ជំនាន់ថ្មី និងអ៊ីនធឺណិតស្ថិរ (យ៉ាងតិច ២ Mbps)។

## ២. ចុះឈ្មោះសម្រាប់ការប្រើមិនមែនពាណិជ្ជកម្ម

1. ចូល [earthengine.google.com](https://earthengine.google.com/) ហើយចុច **Get Started**។
2. ជ្រើស **Use without charge** → **Unpaid usage** → ប្រភេទ **Academia & Research**។
3. បង្កើត **Google Cloud Project** ថ្មី (ឧ. `ee-yourname`) ឬជ្រើសគម្រោងដែលមានស្រាប់។
4. បំពេញសំណួរខ្លីអំពីការប្រើប្រាស់ (ឧ. «វគ្គសិក្សា GIS និង Remote Sensing នៅសាកលវិទ្យាល័យ»)។
5. បើក [code.earthengine.google.com](https://code.earthengine.google.com/)។ ប្រសិនបើត្រូវបានសួរ ជ្រើសគម្រោង Cloud ដែលទើបបង្កើត។

!!! warning "លក្ខខណ្ឌអាចប្ដូរ"
    ដំណើរការចុះឈ្មោះ និងលក្ខខណ្ឌប្រើប្រាស់របស់ Earth Engine ត្រូវបានកែប្រែជាច្រើនដង។ ប្រសិនបើអេក្រង់ខុសពីការពិពណ៌នានេះ សូមធ្វើតាមការណែនាំលើគេហទំព័រ Earth Engine ផ្ទាល់។

## ៣. រៀបចំ Code Editor

- ផ្ទាំង **Scripts → NEW → Repository**៖ បង្កើត repository `applied-gis` សម្រាប់វគ្គនេះ។
- ដាក់ឈ្មោះស្គ្រីបតាមលំហាត់៖ `lab01` `lab02` …។
- **Settings (⚙)**៖ អាចបិទ «Auto-run» និងប្ដូរទំហំអក្សរ។

## ៤. ដំណោះស្រាយបញ្ហាទូទៅ

| បញ្ហា | ដំណោះស្រាយ |
|---|---|
| «Not signed up for Earth Engine» | បញ្ចប់ការចុះឈ្មោះ ហើយរង់ចាំពីរបីនាទី |
| «No project selected» | ចុចរូបគណនី (ខាងស្ដាំលើ) → ជ្រើសគម្រោង Cloud |
| ផែនទីមិនបង្ហាញ | ពិនិត្យអ៊ីនធឺណិត · បិទកម្មវិធីបន្ថែមកម្មវិធីរុករកដែលបិទ script |
| Task នាំចេញ «Failed» | អានសារក្នុង Tasks · ពិនិត្យ maxPixels និងទំហំ Google Drive |
