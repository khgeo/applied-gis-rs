# មេរៀនទី១០៖ ព្រៃឈើ និងការបាត់បង់ព្រៃ

!!! info "ព័ត៌មានមេរៀន"
    **រយៈពេលបង្រៀនដែលស្នើ៖ ៣ ម៉ោង** · មេរៀនទី ១០ ក្នុងចំណោម ១៥

[:material-presentation-play: ស្លាយបង្រៀនមេរៀននេះ](../slides/lesson-10.html){ .md-button target="_blank" }

ក្នុងរយៈពេលពីរទសវត្សរ៍ចុងក្រោយ កម្ពុជាស្ថិតក្នុងចំណោមប្រទេសដែលមានអត្រាបាត់បង់គម្របដើមឈើខ្ពស់ជាងគេក្នុងតំបន់។ ការពង្រីកកសិកម្ម ដីសម្បទានសេដ្ឋកិច្ច ការកាប់ឈើ និងការតាំងលំនៅថ្មី បានប្ដូរទេសភាពនៅខេត្តជាច្រើន។ សំណួរ «បាត់បង់ប៉ុន្មាន នៅទីណា និងពេលណា?» ជាសំណួរដែលអ្នកធ្វើគោលនយោបាយ អង្គការអភិរក្ស និងអ្នកស្រាវជ្រាវសួរជានិច្ច។

មេរៀននេះបង្រៀនការប្រើ **Hansen Global Forest Change** ក្នុង Earth Engine ដើម្បីវាស់ការបាត់បង់គម្របដើមឈើតាមឆ្នាំ តាមខេត្ត និងក្នុងតំបន់ការពារ ព្រមទាំងដែនកំណត់សំខាន់ៗរបស់វា៖ និយមន័យ «ដើមឈើ» កម្រិតគម្រប និងភាពខុសគ្នារវាងព្រៃធម្មជាតិ និងចម្ការ។

---

## ១០.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. ពិពណ៌នាក្រុមរលកនៃ Hansen GFC ហើយពន្យល់ភាពខុសគ្នារវាងគម្របដើមឈើ និងព្រៃ។
2. កំណត់ព្រៃឆ្នាំ ២០០០ ដោយកម្រិតគម្រប ហើយពន្យល់ឥទ្ធិពលនៃកម្រិតលើលទ្ធផល។
3. គណនាផ្ទៃបាត់បង់តាមឆ្នាំ និងតាមខេត្ត ដោយ pixelArea និង reducer ជាក្រុម។
4. ប្រៀបធៀបអត្រាបាត់បង់ក្នុង តំបន់ទ្រនាប់ និងក្រៅតំបន់ការពារ (WDPA) ហើយពន្យល់ការលំអៀងទីតាំង។
5. ផ្ទៀងផ្ទាត់ការបាត់បង់ជាមួយរូបភាព Sentinel-2/Landsat ហើយរាយការណ៍ដែនកំណត់។

### ចំណេះដឹងមុនត្រូវមាន

- [មេរៀនទី៤](lesson-04.md)៖ reducer ជាក្រុម និង pixelArea · [មេរៀនទី៦](lesson-06.md)៖ ការវាយតម្លៃភាពត្រឹមត្រូវ។
- សៀវភៅទី៣៖ ការរកការផ្លាស់ប្ដូរ (change detection)។

## ១០.២. ស្ថានភាពបើកមេរៀន៖ ដែនជម្រកសត្វព្រៃព្រៃឡង់

ព្រៃឡង់ ជាតំបន់ព្រៃទំនាបធំមួយក្នុងចំណោមតំបន់ចុងក្រោយនៃឥណ្ឌូចិន ដែលលាតសន្ធឹងលើខេត្តកំពង់ធំ ក្រចេះ ស្ទឹងត្រែង និងព្រះវិហារ។ វាត្រូវបានប្រកាសជាដែនជម្រកសត្វព្រៃនៅឆ្នាំ ២០១៦ ហើយរបាយការណ៍ជាច្រើនបានលើកឡើងពីការបាត់បង់ព្រៃនៅទីនោះ។ អង្គការមួយសួរអ្នកថា៖ ការបាត់បង់ក្នុងព្រៃឡង់ប្ដូរយ៉ាងណាមុន និងក្រោយឆ្នាំ ២០១៦? ហើយវាខ្ពស់ ឬទាបជាងតំបន់ជុំវិញ?

សំណួរដែលមេរៀននេះឆ្លើយ៖

- តើ «ព្រៃ» ត្រូវកំណត់យ៉ាងដូចម្ដេច ពីទិន្នន័យគម្របដើមឈើ?
- តើត្រូវគណនាការបាត់បង់តាមឆ្នាំ និងតាមតំបន់យ៉ាងណា?
- តើការប្រៀបធៀបក្នុង និងក្រៅតំបន់ការពារ បង្ហាញប្រសិទ្ធភាពបានឬទេ?

## ១០.៣. ទ្រឹស្ដីស្នូល

### ១០.៣.១. Hansen Global Forest Change

<figure markdown>
--8<-- "assets/svg/agv/a10-hansen.svg"
<figcaption>រូបទី១០.១៖ ផែនទីការបាត់បង់ព្រៃ ៣០ ម ចាប់ពីឆ្នាំ ២០០១។</figcaption>
</figure>

!!! note "អានរូបនេះ"
    - treecover2000 ជាគម្របដើមឈើ (%) មិនមែន «ព្រៃ» ទេ៖ អ្នកប្រើត្រូវជ្រើសកម្រិត (ឧ. ≥ ៣០%)។
    - lossyear ប្រាប់ឆ្នាំដែលដើមឈើត្រូវបាត់ (ជម្រះ ឬស្លាប់) ក្នុងក្រឡា ៣០ ម។
    - gain គ្របតែ ២០០០–២០១២ ហើយមិនអាចដកពី loss ដើម្បីបាន «ការផ្លាស់ប្ដូរសុទ្ធ» បានទេ។


**Hansen GFC** (Hansen et al., ២០១៣ និងកំណែបន្តបន្ទាប់) ជាផែនទីពិភពលោកនៃគម្របដើមឈើ និងការបាត់បង់ ពី Landsat នៅក្រឡា ៣០ ម៉ែត្រ។ វាត្រូវបានធ្វើបច្ចុប្បន្នភាពរៀងរាល់ឆ្នាំ៖ ឈ្មោះ asset រួមបញ្ចូលឆ្នាំចុងក្រោយ និងកំណែ (ឧ. `2023_v1_11` គ្របដល់ឆ្នាំ ២០២៣)។ ពិនិត្យកាតាឡុក Earth Engine សម្រាប់កំណែថ្មីបំផុតមុនចាប់ផ្ដើមការងារ។

```javascript
var gfc = ee.Image('UMD/hansen/global_forest_change_2023_v1_11');
print(gfc.bandNames());   // treecover2000 loss gain lossyear first_* last_* datamask
var kh = ee.FeatureCollection('FAO/GAUL/2015/level0').filter(ee.Filter.eq('ADM0_NAME', 'Cambodia'));
Map.centerObject(kh, 7);
Map.addLayer(gfc.select('treecover2000').clip(kh), {min: 0, max: 100, palette: ['white', 'green']}, 'treecover2000');
Map.addLayer(gfc.select('lossyear').selfMask().clip(kh), {min: 1, max: 23, palette: ['yellow', 'orange', 'red']}, 'lossyear');
```

| ក្រុមរលក | អត្ថន័យ |
|---|---|
| `treecover2000` | គម្របពំនូកដើមឈើ (%) ឆ្នាំ ២០០០ សម្រាប់រុក្ខជាតិខ្ពស់ជាង ៥ ម |
| `loss` | ១ = ក្រឡាបាត់បង់គម្របដើមឈើ ក្នុងឆ្នាំណាមួយ ២០០១–ឆ្នាំចុងក្រោយ |
| `lossyear` | ឆ្នាំបាត់បង់ (១ = ២០០១ · ២៣ = ២០២៣) · ០ = គ្មាន |
| `gain` | ១ = គម្របដើមឈើកើនឡើង ២០០០–២០១២ |
| `datamask` | ០ គ្មានទិន្នន័យ · ១ ដី · ២ ទឹក |

«Loss» ក្នុង Hansen មានន័យថា **ការបាត់បង់គម្របដើមឈើ** នៅកម្រិតក្រឡា ទោះបីជាដោយការកាប់ ភ្លើង ខ្យល់ព្យុះ ឬការច្រូតចម្ការក៏ដោយ។ វាមិនមែន «ការបាត់បង់ព្រៃ» តាមន័យច្បាប់ ឬការប្រើប្រាស់ដីទេ។

### ១០.៣.២. គម្របដើមឈើ ≠ ព្រៃ

<figure markdown>
--8<-- "assets/svg/agv/a10-treecover.svg"
<figcaption>រូបទី១០.២៖ Hansen វាស់ដើមឈើ មិនមែនប្រភេទព្រៃ។</figcaption>
</figure>

!!! note "អានរូបនេះ"
    - Hansen កំណត់ «ដើមឈើ» ថាជារុក្ខជាតិខ្ពស់ជាង ៥ ម៉ែត្រ ដោយមិនបែងចែកព្រៃធម្មជាតិ និងចម្ការទេ។
    - នៅកម្ពុជា ចម្ការកៅស៊ូ ស្វាយចន្ទី និងអាកាស្យា មានច្រើន៖ loss ខ្លះគឺជាការច្រូតចម្ការ។
    - ដើម្បីនិយាយពី «ព្រៃធម្មជាតិ» ត្រូវរួមជាមួយផែនទីព្រៃថ្នាក់ជាតិ ឬទិន្នន័យចម្ការ។


Hansen មិនបែងចែកព្រៃធម្មជាតិ ពីចម្ការទេ។ នៅកម្ពុជា ចម្ការកៅស៊ូ ស្វាយចន្ទី អាកាស្យា និងប្រេងដូង មានកម្ពស់លើស ៥ ម ហើយត្រូវបានរាប់ជា «ដើមឈើ»។ លទ្ធផលពីរ៖

- **ការច្រូតចម្ការ** (ឧ. កាប់កៅស៊ូចាស់ ដើម្បីដាំឡើងវិញ) ត្រូវបានរាប់ជា loss។
- **ការប្ដូរព្រៃទៅជាចម្ការកៅស៊ូ** អាចបង្ហាញជា loss ក្នុងឆ្នាំកាប់ ប៉ុន្តែប៉ុន្មានឆ្នាំក្រោយ ចម្ការថ្មីក្លាយជា «ដើមឈើ» វិញ។

ដូច្នេះ ពេលនិយាយពី «ការបាត់បង់ព្រៃធម្មជាតិ» ត្រូវរួមបញ្ចូលផែនទីព្រៃថ្នាក់ជាតិ ផែនទីចម្ការ ឬពិនិត្យដោយភ្នែកលើរូបភាពគុណភាពខ្ពស់។

### ១០.៣.៣. កំណត់ព្រៃឆ្នាំ ២០០០ ដោយកម្រិត

<figure markdown>
--8<-- "assets/svg/agv/a10-threshold.svg"
<figcaption>រូបទី១០.៣៖ និយមន័យ ជាការសម្រេចចិត្ត។</figcaption>
</figure>

!!! note "អានរូបនេះ"
    - ពីកម្រិត ១០% ទៅ ៥០% ផ្ទៃ «ព្រៃ» ថយពី ៤៥,៩ ទៅ ២២,៩ គម² លើតំបន់ដដែល។
    - ការបាត់បង់ក៏ប្ដូរតាម៖ loss ត្រូវវាស់តែក្នុងក្រឡាដែលជា «ព្រៃ» ឆ្នាំ ២០០០ តាមកម្រិតដែលបានជ្រើស។
    - រាយការណ៍កម្រិតជានិច្ច ហើយប្រើកម្រិតដូចគ្នាពេលប្រៀបធៀបខេត្ត ឬឆ្នាំ។


`treecover2000` ជា % ដូច្នេះអ្នកប្រើត្រូវជ្រើសកម្រិតដើម្បីកំណត់ «ព្រៃ»។ Global Forest Watch ប្រើ **≥ ៣០%** ជាលំនាំដើម ហើយ FAO ប្រើ **≥ ១០%** (ជាមួយផ្ទៃអប្បបរមា ០,៥ ហិកតា)។ ការបាត់បង់ត្រូវវាស់តែក្នុងក្រឡាដែលជាព្រៃឆ្នាំ ២០០០ ប៉ុណ្ណោះ៖

```javascript
var forest2000 = gfc.select('treecover2000').gte(30);
var loss = gfc.select('loss').and(forest2000);                       // បាត់បង់ក្នុងព្រៃ ២០០០
var area = ee.Image.pixelArea().divide(1e4);                         // ហិកតា
var stats = area.updateMask(forest2000).rename('forest2000_ha')
  .addBands(area.updateMask(loss).rename('loss_ha'))
  .reduceRegion({reducer: ee.Reducer.sum(), geometry: kh.geometry(), scale: 30, maxPixels: 1e13, tileScale: 4});
print('ព្រៃ ២០០០ និងការបាត់បង់ (ហិកតា)', stats);
```

ចំណាំថាការគណនាលើប្រទេសទាំងមូលនៅ ៣០ ម ត្រូវការ `maxPixels` ធំ ហើយអាចត្រូវ Export ជំនួស print។

    - ក្រាបលំនាំនេះជាស៊េរីក្លែងធ្វើ៖ លំហាត់ទី១០ គណនាតួលេខពិតសម្រាប់ខេត្តរបស់អ្នក។

reducer ជាក្រុម (មេរៀនទី៤) ផ្ដល់ផ្ទៃបាត់បង់ក្នុងឆ្នាំនីមួយៗ ក្នុងការហៅតែមួយ៖

var byYear = area.addBands(gfc.select('lossyear')).updateMask(loss).reduceRegion({

- **ពិនិត្យគំរូ**៖ ជ្រើសក្រឡាបាត់បង់ចៃដន្យ ៥០ ហើយមើលរូបភាពមុន និងក្រោយ (Landsat · Sentinel-2 · Google Earth) ដើម្បីដឹងថាវាជាព្រៃធម្មជាតិ ឬចម្ការ ហើយជាមូលហេតុអ្វី។
- **រកដោយខ្លួនឯង**៖ សម្រាប់តំបន់តូច ឬឆ្នាំថ្មីជាង Hansen ប្រៀបធៀប NDVI ពី composite ពីរឆ្នាំក្នុងរដូវដូចគ្នា (រដូវប្រាំង)៖

function dryNDVI(y) {
  return ee.ImageCollection('COPERNICUS/S2_SR_HARMONIZED').filterBounds(pa)
    .filterDate(y + '-01-01', y + '-04-30').filter(ee.Filter.lt('CLOUDY_PIXEL_PERCENTAGE', 30))
    .median().normalizedDifference(['B8', 'B4']);
}
var lost = dryNDVI(2019).gt(0.6).and(dryNDVI(2024).lt(0.35));
Map.addLayer(lost.selfMask().clip(pa), {palette: ['red']}, 'NDVI ធ្លាក់ ២០១៩–២០២៤');

## ១០.៤. ឧទាហរណ៍ដែលបានដោះស្រាយ៖ ព្រៃឡង់ មុន និងក្រោយឆ្នាំ ២០១៦

### ជំហានទី១៖ តំបន់ និងស្រទាប់

ប្រើកូដក្នុងផ្នែក ១០.៣.៥ ដើម្បីបាន `pa` (ព្រៃឡង់) និង `buffer` (ទ្រនាប់ ១០ គម)។ ពិនិត្យលើផែនទីថាព្រំដែន WDPA ត្រូវនឹងការរំពឹងទុក។ កំណត់ `forest2000` (≥ ៣០%) និង `loss` (ផ្នែក ១០.៣.៣)។

### ជំហានទី២៖ អត្រាតាមរយៈពេល

```javascript
function lossRate(geom, y0, y1) {
  var inPeriod = gfc.select('lossyear').gte(y0 - 2000).and(gfc.select('lossyear').lte(y1 - 2000)).and(forest2000);
  var s = area.updateMask(forest2000).rename('f').addBands(area.updateMask(inPeriod).rename('l'))
    .reduceRegion({reducer: ee.Reducer.sum(), geometry: geom, scale: 30, maxPixels: 1e13, tileScale: 8});
  return ee.Number(s.get('l')).divide(s.get('f')).multiply(100).divide(y1 - y0 + 1);   // %/ឆ្នាំ
}
print('ព្រៃឡង់ ២០១១–២០១៥', lossRate(pa.geometry(), 2011, 2015));
print('ព្រៃឡង់ ២០១៧–២០២៣', lossRate(pa.geometry(), 2017, 2023));
print('ទ្រនាប់ ២០១៧–២០២៣', lossRate(buffer, 2017, 2023));
```

អត្រាប្រចាំឆ្នាំ (%/ឆ្នាំ) អនុញ្ញាតឲ្យប្រៀបធៀបរយៈពេលដែលមានចំនួនឆ្នាំខុសគ្នា។ ឆ្នាំ ២០១៦ ត្រូវបានដកចេញ ព្រោះវាជាឆ្នាំអន្តរកាល។

### ជំហានទី៣៖ ក្រាបតាមឆ្នាំ

ប្រើកូដផ្នែក ១០.៣.៤ ជាមួយ `pa.geometry()` ដើម្បីបានក្រាបតាមឆ្នាំ។ សម្គាល់ឆ្នាំដែលមានការបាត់បង់ខ្ពស់។

### ជំហានទី៥៖ បកស្រាយ

> «ដោយប្រើ Hansen GFC v1.11 (គម្របដើមឈើ ≥ ៣០%) អត្រាបាត់បង់ប្រចាំឆ្នាំក្នុងព្រៃឡង់ ត្រូវបានគណនាសម្រាប់ ២០១១–២០១៥ និង ២០១៧–២០២៣ ហើយប្រៀបធៀបជាមួយតំបន់ទ្រនាប់ ១០ គម។ ការពិនិត្យគំរូ ៥០ ក្រឡា បង្ហាញភាគរយនៃការបាត់បង់ដែលជាព្រៃធម្មជាតិ។»

!!! warning "អ្វីដែលយើងមិនអាចសន្និដ្ឋាន"
    ការប្ដូរអត្រាមុន និងក្រោយឆ្នាំ ២០១៦ មិនបញ្ជាក់ថាការប្រកាសជាដែនជម្រក បានបណ្ដាលឲ្យវាប្ដូរទេ៖ តម្លៃកសិផល ផ្លូវថ្មី និងគោលនយោបាយផ្សេង ក៏ប៉ះពាល់ដែរ។ ការប្រៀបធៀបជាមួយតំបន់ទ្រនាប់ មិនមែនការវាយតម្លៃផលប៉ះពាល់ (impact evaluation) ពេញលេញទេ។

## ១០.៥. សកម្មភាពអនុវត្ត

- **លំហាត់ទី១០**៖ គណនាព្រៃឆ្នាំ ២០០០ និងការបាត់បង់តាមឆ្នាំ សម្រាប់ខេត្តទាំង ២៥ ប្រៀបធៀបកម្រិត ១០% និង ៣០% ហើយវិភាគតំបន់ការពារមួយ ជាមួយការពិនិត្យគំរូ។ មើល [លំហាត់ទី១០](../workbook/lab-10.md)។
- **ក្នុងថ្នាក់**៖ ក្រុមនីមួយៗពិនិត្យក្រឡាបាត់បង់គំរូ ២០ លើ Google Earth ហើយថ្នាក់បូកសរុបភាគរយនៃព្រៃធម្មជាតិ ចម្ការ និងកំហុស។

## ១០.៦. ការយល់ច្រឡំដែលត្រូវប្រុងប្រយ័ត្ន

**១. «Hansen loss = ការកាប់ព្រៃខុសច្បាប់»**
Loss គឺការបាត់បង់គម្របដើមឈើ ដោយមូលហេតុណាក៏ដោយ រួមទាំងការច្រូតចម្ការស្របច្បាប់ និងភ្លើង។

**២. «ផ្ទៃព្រៃ = ចំនួនក្រឡា treecover2000 > ០»**
ត្រូវជ្រើសកម្រិតគម្រប (១០% ឬ ៣០%) ហើយលទ្ធផលប្ដូរច្រើនតាមកម្រិត។

**៣. «ព្រៃឆ្នាំ ២០២៣ = ព្រៃ ២០០០ − loss + gain»**
gain គ្របតែ ២០០០–២០១២ ហើយវិធីសាស្ត្រខុសពី loss។ Hansen មិនផ្ដល់គម្របឆ្នាំបច្ចុប្បន្នដោយផ្ទាល់ទេ។

**៤. «តំបន់ការពារដែលមានការបាត់បង់តិច មានប្រសិទ្ធភាព»**
វាប្រហែលជាមានការបាត់បង់តិច ព្រោះវាឆ្ងាយ និងពិបាកចូលដល់។ ការវាយតម្លៃប្រសិទ្ធភាពត្រូវការការប្រៀបធៀបដែលគ្រប់គ្រងលក្ខខណ្ឌ។

**៥. «ផ្ទៃ = ចំនួនក្រឡា × ៩០០ ម²»**
ក្រឡា Hansen ជា ០,០០០២៥ ដឺក្រេ៖ ផ្ទៃពិតខុសតាមរយៈទទឹង។ ប្រើ pixelArea (មេរៀនទី៤)។

## ១០.៧. សេចក្ដីសង្ខេបមេរៀន

Hansen GFC ផ្ដល់គម្របដើមឈើឆ្នាំ ២០០០ និងឆ្នាំបាត់បង់ ២០០១–បច្ចុប្បន្ន នៅក្រឡា ៣០ ម។ យើងកំណត់ព្រៃឆ្នាំ ២០០០ ដោយកម្រិតគម្រប (≥ ៣០% ឬ ≥ ១០%) វាស់ការបាត់បង់តែក្នុងព្រៃនោះ ហើយគណនាផ្ទៃតាមឆ្នាំ និងតាមតំបន់ដោយ pixelArea និង group()។

Hansen វាស់ដើមឈើ មិនមែនប្រភេទព្រៃទេ៖ ចម្ការកៅស៊ូ និងស្វាយចន្ទី ត្រូវបានរាប់ ហើយការច្រូតចម្ការក្លាយជា loss។ ការប្រៀបធៀបតំបន់ការពារត្រូវប្រើអត្រា និងប្រុងប្រយ័ត្នចំពោះការលំអៀងទីតាំង ហើយលទ្ធផលត្រូវផ្ទៀងផ្ទាត់ដោយការពិនិត្យគំរូជាមួយរូបភាព។

!!! abstract "គំនិតស្នូលនៃមេរៀន"
    ផែនទីការបាត់បង់ព្រៃ ឆ្លើយសំណួរ «ដើមឈើបាត់នៅទីណា និងពេលណា» បានល្អ។ សំណួរ «ហេតុអ្វី» និង «ព្រៃប្រភេទអ្វី» ត្រូវការទិន្នន័យបន្ថែម និងការពិនិត្យដោយភ្នែកមនុស្ស។

## ១០.៩. សំណួររំលឹក និងវាយតម្លៃ

### ក. សំណួរយល់ដឹង

1. រាយក្រុមរលកប្រាំនៃ Hansen GFC ហើយពន្យល់ក្រុមរលកនីមួយៗ។
2. ហេតុអ្វីគម្របដើមឈើ មិនមែនជាព្រៃ? ផ្ដល់ឧទាហរណ៍ពីរពីកម្ពុជា។
3. ហេតុអ្វីត្រូវវាស់ការបាត់បង់តែក្នុងក្រឡាដែលជាព្រៃឆ្នាំ ២០០០?
4. ហេតុអ្វីមិនអាចគណនាគម្របបច្ចុប្បន្នដោយ treecover2000 − loss + gain?
5. ពន្យល់ការលំអៀងទីតាំង ពេលប្រៀបធៀបតំបន់ការពារ។

### ខ. សំណួរអនុវត្តគោលគំនិត

6. សរសេរកូដគណនាភាគរយនៃព្រៃឆ្នាំ ២០០០ (≥ ៣០%) ដែលបាត់បង់ ២០០១–២០២៣ សម្រាប់ខេត្តរបស់អ្នក។
7. ខេត្តមួយមានការបាត់បង់ ៥០ ០០០ ហិកតា ហើយខេត្តមួយទៀត ១០ ០០០ ហិកតា។ តើអ្នកអាចសន្និដ្ឋានថាខេត្តទីមួយ «អាក្រក់ជាង» ទេ? ត្រូវការព័ត៌មានអ្វីបន្ថែម?
8. ក្រាបតាមឆ្នាំបង្ហាញការកើនឡើងខ្លាំងក្នុងឆ្នាំមួយ។ រាយមូលហេតុបីដែលអាចកើតឡើង។
9. សរសេរកូដបង្កើតតំបន់ទ្រនាប់ ៥ គម ជុំវិញតំបន់ការពារមួយ (ដោយមិនរួមតំបន់ការពារ)។
10. ស្នើវិធីបែងចែក loss ដែលជាព្រៃធម្មជាតិ ពី loss ដែលជាចម្ការ ដោយប្រើមេរៀនមុនៗ។

### គ. កិច្ចការខ្លី

ជ្រើសតំបន់ការពារមួយនៅកម្ពុជា (ក្រៅពីព្រៃឡង់)។ គណនាអត្រាបាត់បង់ប្រចាំឆ្នាំក្នុង និងក្នុងទ្រនាប់ ១០ គម សម្រាប់ ២០០១–២០១០ និង ២០១១–២០២៣ ហើយសរសេរកថាខណ្ឌមួយបកស្រាយ ដោយរួមបញ្ចូលដែនកំណត់។

- ប្រធានបទព្រៃឈើអាចរសើប។ លើកទឹកចិត្តនិស្សិតឲ្យរាយការណ៍តួលេខ និងដែនកំណត់ ដោយមិនធ្វើការចោទប្រកាន់ដែលទិន្នន័យមិនអាចបញ្ជាក់។

### គ. ការភ្ជាប់ទៅមេរៀនបន្ទាប់

ដីព្រៃដែលបាត់បង់ ភាគច្រើនក្លាយជាដីកសិកម្ម៖ ចម្ការ ដំណាំ និងស្រែ។ ស្រែជាគម្របដីកសិកម្មសំខាន់បំផុតនៅកម្ពុជា ហើយវាដាំក្នុងរដូវដែលពពកគ្របដណ្ដប់ច្រើនបំផុត។

> តើយើងអាចធ្វើផែនទីស្រែ ក្នុងរដូវវស្សាដែលមានពពក បានដោយរបៀបណា?

សំណួរនេះនាំទៅ **មេរៀនទី១១៖ កសិកម្ម និងការធ្វើផែនទីស្រែ**។
