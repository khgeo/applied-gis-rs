## គោលបំណងវគ្គសិក្សា

បន្ទាប់ពីបញ្ចប់វគ្គ និស្សិតអាច៖

1. ពន្យល់ពីរបៀបដែលការគណនាលើពពក ប្ដូររបៀបធ្វើការវិភាគរូបភាពផ្កាយរណប និងដែនកំណត់របស់វា។
2. សរសេរស្គ្រីប JavaScript ក្នុង Earth Engine ដើម្បីត្រង លុបពពក បង្កើត composite និងគណនាស្ថិតិតាមតំបន់។
3. វិភាគស៊េរីពេលវេលា និងចាត់ថ្នាក់គម្របដីលើតំបន់ធំ ជាមួយការវាយតម្លៃភាពត្រឹមត្រូវ។
4. អនុវត្តវិធីសាស្ត្រលើបញ្ហាពិតនៅកម្ពុជា៖ ទឹកជំនន់ គ្រោះរាំងស្ងួត ព្រៃឈើ កសិកម្ម និងទីក្រុង។
5. រួមបញ្ចូលលទ្ធផល Earth Engine ជាមួយ QGIS ហើយចែករំលែកវាជាផែនទី របាយការណ៍ និងកម្មវិធីវេប។

## សេចក្ដីណែនាំអំពីកូដ

កូដក្នុងសៀវភៅនេះសរសេរសម្រាប់ **Earth Engine JavaScript API** ក្នុង Code Editor។ កូដភាគច្រើនខ្លី (១០–៤០ បន្ទាត់) ហើយមានមតិយោបល់ជាភាសាខ្មែរ។ ឈ្មោះទិន្នន័យ (ឧ. `COPERNICUS/S2_SR_HARMONIZED`) អាចប្ដូរតាមពេលវេលា៖ ពិនិត្យកាតាឡុក Earth Engine ប្រសិនបើកូដបង្ហាញកំហុស «asset not found»។
