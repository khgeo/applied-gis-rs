# ស្លាយបង្រៀន

ស្លាយពេញលេញសម្រាប់បង្រៀនមេរៀននីមួយៗ (៣ ម៉ោង)។ ពិសោធន៍អន្តរកម្ម ការប្រៀបធៀបរូបភាព និងសំណួរពិនិត្យខ្លួនឯង ដំណើរការ **ផ្ទាល់ក្នុងស្លាយ** ដោយមិនចាំបាច់បើកគេហទំព័រ ហើយប្រើបានដោយគ្មានអ៊ីនធឺណិត។
