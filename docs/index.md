# សៀវភៅទី៤៖ អនុវត្តន៍ GIS និងការយកព័ត៌មានពីចម្ងាយ

## សម្រាប់វគ្គសិក្សា ១ ឆមាស · ៤៥ ម៉ោង · ១៥ មេរៀន · ១៥ លំហាត់ Earth Engine · ជាភាសាខ្មែរ

---

សៀវភៅនេះជាឯកសារបង្រៀនសម្រាប់មុខវិជ្ជា **អនុវត្តន៍ GIS និងការយកព័ត៌មានពីចម្ងាយ (Applied GIS and Remote Sensing)** កម្រិតបរិញ្ញាបត្រ ឆ្នាំទី៣ ឆមាសទី២ ដេប៉ាតឺម៉ង់ភូមិវិទ្យា និងរៀបចំដែនដី។ វាមាន **១៥ មេរៀនទ្រឹស្ដី និងអនុវត្ត** (៣ ម៉ោងក្នុងមួយមេរៀន) និង **សៀវភៅអនុវត្ត ១៥ លំហាត់** ដែលប្រើ **Google Earth Engine** ដើម្បីវិភាគរូបភាពផ្កាយរណបរាប់ពាន់ផ្ទាំងលើកម្ពុជា ដោយមិនចាំបាច់ទាញយកទិន្នន័យ។

សៀវភៅទី២ និងទី៣ បង្រៀន «ហេតុអ្វី» និង «យ៉ាងដូចម្ដេច» លើរូបភាព ឬស្រទាប់មួយៗក្នុង QGIS។ សៀវភៅនេះបង្រៀនរបៀបធ្វើការងារដដែលនោះ **លើប្រទេសទាំងមូល និងលើរយៈពេលរាប់ឆ្នាំ** ហើយអនុវត្តវាលើបញ្ហាពិតរបស់កម្ពុជា៖ ទឹកជំនន់ គ្រោះរាំងស្ងួត ការបាត់បង់ព្រៃ ស្រែ និងការពង្រីកទីក្រុង។

## ស៊េរីសៀវភៅទាំង ៤

សៀវភៅនេះជាផ្នែកមួយនៃស៊េរីសម្រាប់ឆ្នាំទី២ និងទី៣។ មើលស៊េរីទាំងមូលនៅ [khgeo.github.io](https://khgeo.github.io/)។

| សៀវភៅ | ចំណងជើង | ឆ្នាំ/ឆមាស |
|---|---|---|
| ទី១ | [ផែនទីវិទ្យា](https://khgeo.github.io/cartography/) | ឆ្នាំទី២ ឆមាសទី១ |
| ទី២ | [មូលដ្ឋានគ្រឹះនៃ GIS](https://khgeo.github.io/gis-fundamentals/) | ឆ្នាំទី២ ឆមាសទី២ |
| ទី៣ | [មូលដ្ឋានគ្រឹះនៃការយកព័ត៌មានពីចម្ងាយ](https://khgeo.github.io/remote-sensing/) | ឆ្នាំទី៣ ឆមាសទី១ |
| ទី៤ | អនុវត្តន៍ GIS និងការយកព័ត៌មានពីចម្ងាយ ← សៀវភៅនេះ | ឆ្នាំទី៣ ឆមាសទី២ |

!!! abstract "អ្វីដែលសៀវភៅនេះបង្រៀន និងមិនបង្រៀន"
    សៀវភៅនេះបង្រៀន **ការគណនាលើពពក (Google Earth Engine) JavaScript សម្រាប់ការវិភាគលំហ ការត្រង និងការបង្កើត composite ស្ថិតិតាមតំបន់ ស៊េរីពេលវេលា ការចាត់ថ្នាក់ដោយ Random Forest** និង **ការអនុវត្ត** លើទឹកជំនន់ គ្រោះរាំងស្ងួត ទីសណ្ឋាន ព្រៃឈើ កសិកម្ម ទីក្រុង និងការសម្រេចចិត្តពហុលក្ខខណ្ឌ ព្រមទាំងការចែករំលែកលទ្ធផលជាកម្មវិធីវេប។

    **រូបវិទ្យានៃរលក សញ្ញាណស្ពិចត្រាល់ សន្ទស្សន៍ និងទ្រឹស្ដីការចាត់ថ្នាក់** ជាខ្លឹមសារសៀវភៅទី៣ ហើយ **ស្រទាប់វ៉ិចទ័រ មូលទិន្នន័យ បាហ្វ័រ និងការត្រួតស្រទាប់** ជាខ្លឹមសារសៀវភៅទី២។ សៀវភៅនេះប្រើពួកវាជាឧបករណ៍ ដោយមិនបង្រៀនឡើងវិញ។
